# Getting help

- A question about installing or running TandemLLM: [Discussions, Q&A](https://github.com/TandemLLM/TandemEngine/discussions/categories/q-a)
- A bug, a slow number or a wrong doc: open an issue on the repository it is in, [TandemEngine](https://github.com/TandemLLM/TandemEngine/issues/new/choose) or [TandemApp](https://github.com/TandemLLM/TandemApp/issues/new)
- A security problem: never in public, see [SECURITY.md](SECURITY.md)
- Enterprise solutions, support and the commercial license: [mail@0xbakeer.com](mailto:mail@0xbakeer.com)

The documentation: [tandemengine.0xbakeer.com](https://tandemengine.0xbakeer.com) and [tandemapp.0xbakeer.com](https://tandemapp.0xbakeer.com). Releases are announced by [@TandemLLM](https://x.com/TandemLLM) on X.
